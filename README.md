## Install

Press **Install in Stremio** above, or open **Addons** in Stremio and paste this link into the search bar:

```
https://hertn.github.io/childhood-movie-list/manifest.json
```

Posters, descriptions and trailers come from Stremio's built-in Cinemeta. This addon only lists the films.
